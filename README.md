# Hi, I'm Ahmet Resul Kuru 👋

### Backend & AI Developer · Python, Django, FastAPI, LLMs

I build backend systems that put AI into production: REST APIs and microservices, queue-based GPU/CPU workloads, and LLM features that are measured, guarded and monitored. I have 4+ years of experience, currently at **CranioCatch**, where I work on AI-based dental imaging in healthcare.

---

### 🧠 What I work on

- **LLM agents and tool calling.** I build agents that take real actions, with approval steps and guardrails, and I improve them with evaluation scenarios.
- **LLM features in production.** Structured (JSON) output for decision support, RAG, prompt engineering, MCP.
- **Deep learning in production.** I turn PyTorch, YOLO (2D) and nnU-Net (3D) models into services, reports and user interfaces. I work with DICOM, PACS and NIfTI.
- **Speech.** Real-time speech-to-text services with faster-whisper.
- **Backend and infrastructure.** Django/DRF and FastAPI APIs; Celery + Redis with separate GPU and CPU workers, retries and timeouts; PostgreSQL schema design and query tuning; monitoring with Prometheus and Grafana.
